# User Guide: One-Click Fixing Rate

This guide explains how to secure a fixed-term, fixed-rate loan using Rates Exchange's Interest Rate Markets on top of existing lending protocols such as Aave and Morpho

Key properties:

* **Fully self-custodial** — users retain full control of assets at all times
* **Autonomous execution** — complete rate fixing in under 5 seconds
* **24/7 fixed-rate availability** — rates can be hedged instantly at any time, with no need to wait for lender matching or order fulfillment.
* **Gasless execution** — interacting with ParRate’s interest rate market requires no additional gas tokens
* **Cross-chain abstraction** — ParRate abstracts away the complexity between the loan’s origination chain and the rate market chain, enabling seamless hedging without user-side bridging
